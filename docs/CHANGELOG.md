  disclosed in [`DISCLOSURE.md`](DISCLOSURE.md).

  `HH:MM IST · <author> · <package> · <sponsor if any> · <what> · <commit>`.

  **ENS**.

  `git diff --stat v0-prekickoff..HEAD -- <paths>`. It is the evidence for "≥ 70 % of each integration's final code
  ships in the window" (DECISION §7.2 constraint 2).
